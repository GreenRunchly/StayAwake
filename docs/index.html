Features

Simple controls without the bloat.

☕

Left-Click Toggle

Instantly enable or disable caffeinate -i -m -s with a single click—no password prompt required.

💻

System SleepDisabled

Toggle pmset -a disablesleep 1/0 from the right-click menu so closing the lid won't sleep your Mac.

❄️

Disable Turbo Boost

Load or unload DisableTurboBoost.64bits.kext to keep Intel MacBooks cooler and quieter.

🔐

One-Time Setup

Configures /etc/sudoers.d/stayawake on first privileged action so future toggles need no password.

Requirements & Build

Compile locally in seconds using Xcode Command Line Tools.

  • macOS (tested on macOS 13 Ventura, Intel x86_64)
  • Xcode Command Line Tools (swiftc)
  • Optional: DisableTurboBoost.64bits.kext for Turbo Boost toggle
git clone https://github.com/GreenRunchly/StayAwake.git
cd StayAwake
chmod +x build.sh
./build.sh
open StayAwake.app
